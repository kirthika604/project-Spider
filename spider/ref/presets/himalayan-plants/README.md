Reference data for the Himalayan plants example: Uttarakhand and Himachal
districts, the categories that example uses, and Wikidata ids for its plants.

Nothing here is loaded by default. A project asks for it:

    spider ref load --preset himalayan-plants

Your own project will want its own lists. A reference CSV is three columns -
see `spider settings vocabulary` or load one of your own with
`spider ref load my-places.csv`.
